Types of Data Collected

The school collects student, academic, financial and learning data. Bringing this information together makes it easier to find problems, understand what is happening across the institution and identify practical solutions.

Types of Data

Student Data

  • Student number
  • Name
  • Contact details
  • Email address

Academic Data

  • Marks
  • Attendance
  • Course registration

Financial Data

  • Fees
  • Payments
  • Bursaries

Learning Data

  • LMS logins
  • Assignment submissions
  • Test results
  • Quiz performance

According to reference [1], universities mostly manage these types of records across the SIS and LMS platforms.

Problems

This is where our website connects with the problems schools are currently facing. Faults can arise with each of the following issues, and these are the problems we want to fix.

Problem 1: Duplicate Records

Example: Multiple systems store the same student's information separately. A student's name may appear more than once in the SMS, LMS and Finance system, with different details.

Impact:

  • Incorrect reports
  • Confusion
  • Space consumption

Problem 2: Inconsistent Information

Example: The Finance Department says a student's fees are paid, while the student's system says the fees are unpaid.

Impact:

  • Incorrect decisions
  • Registration delays
  • Loss of income within the school

Problem 3: Delayed Updates

Example: A student changes their cell phone number. The update appears in one system but not in the other systems.

Result:

  • Staff work with outdated information
  • The student won't receive information
  • Lack of communication between both parties

According to reference [2], disconnected systems commonly create inconsistencies and data silos. Data silos happen when information is kept separately and can't be shared effectively between systems, which reduces visibility and weakens decision-making [3].

Data matters because good quality data allows managers, lecturers and administrators to make accurate decisions. Trustworthy information helps the institution monitor student performance, manage finances and improve student success rates. Data management platforms collect, validate, integrate and analyse institutional data to help with decision-making [4].

Solutions

Solution 1: Integrate Systems

Things that must be connected:

  • SMS
  • LMS
  • Finance

Benefits:

  • Information updates automatically
  • Fewer duplicates
  • More space for other things to be stored

Integrated systems improve efficiency and reduce inconsistencies in records [5].

Solution 2: Data Validation

Rules that must be followed:

  • A phone number must contain the correct number of digits
  • Marks must be between 0 and 100

Solution 3: Data Audits

Regularly check:

  • Whether there is missing information
  • Whether there are duplicates within the program
  • Whether there are incorrect records

Benefit: Better data quality.
