    One authoritative source per data item

    Other systems can hold a synchronised copy, but staff must know where a correction is made. Pick a data item to see where that is.

    A repeatable improvement cycle

    1. Define the field and rule

      Agree what "active student" means, who owns the definition and which system is authoritative.

    2. Profile and measure

      Count missing IDs, duplicate profiles, invalid codes and out-of-date synchronisations to set a baseline.

    3. Correct at the source

      Assign issues to authorised data owners. Validate changes and keep an audit trail rather than overwriting records in a report.

    4. Prevent and monitor

      Add validation, staff training and routine exception reports. Track the same measures monthly.

    Then return to step 2 and check whether quality improved.
